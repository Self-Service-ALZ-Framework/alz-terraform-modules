## Git Tagging Convention

Tags follow the format `<module-short-name>/vX.Y.Z`, e.g.:

```bash
git tag avm-res-keyvault-vault/v0.10.2
git push origin avm-res-keyvault-vault/v0.10.2
```

This allows per-module versioning within the monorepo, enabling consumers to pin to specific module versions via git tags.

## Updating This File

When a module is updated to a newer upstream version:

1. Update the vendored module folder contents from the Terraform Registry source.
2. Update the **Latest Version** and **Published** columns in the table above.
3. Create a new git tag: `git tag <module-short-name>/vX.Y.Z`
4. Push the tag: `git push origin <module-short-name>/vX.Y.Z`
